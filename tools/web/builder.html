WISHES

A Digitone II mod, built here in this page from your own copies of Elektron's OS files. Nothing is uploaded anywhere. The page lets you save only a file that is byte for byte one the project's gate cleared. How to reach the hidden functions

Unofficial. Not made, endorsed or supported by Elektron. Wishes is a fork of De-Pattern's dn2mk2-firmware, with extra machines and effects that are not in upstream's releases. For upstream's own cleared builds use the dn2mk2 patcher.

3 · Build

waiting for the files

Save appears only when your build's sha256 is the one in the version's gate record: then it is the very file that passed the project's whole gate (unit tests, the ColdFire emulator, the SHARC runner). Anything else is not offered. Before you flash: back up the +Drive and your projects; the stock OS 1.12 file sent the same way puts the instrument back.
